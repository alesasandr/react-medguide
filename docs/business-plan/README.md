# Материалы для конференции «Наука для жизни» (направление «Шаг в бизнес»)

В этой папке собраны документы проекта **MedGuide** по шаблонам открытой городской научно-практической конференции «Наука для жизни», направление «Шаг в бизнес».

## Документы

| Файл | Описание |
|------|----------|
| [01-biznes-plan.md](01-biznes-plan.md) | Полный бизнес-план по шаблону конференции (титул, содержание, описание идеи, анализ рынка, ценностное предложение, бизнес-модель Остервальдера, операционный и финансовый планы, приложения) |
| [02-pasport-proekta.md](02-pasport-proekta.md) | Паспорт предпринимательского проекта (название, авторы, руководители, краткое описание, ценностное предложение, ЦА, инвестиции, источники финансирования, сроки, доходы, ОПФ) |

Перед сдачей подставьте в оба документа реальные данные: наименование образовательной организации, класс, ФИО участника и научного руководителя, секцию, при необходимости — цифры по инвестициям и срокам.

## Загрузка в личный кабинет

- **Регистрация и подача заявки:** [https://conf.profil.mos.ru/business/register](https://conf.profil.mos.ru/business/register)
- В разделе «Подать заявку» выберите «Регистрация работы обучающегося» или «Регистрация работы представителя образовательной организации», заполните форму и сохраните доклад.

**Требования к файлам при загрузке:**

| Тип материала | Допустимые форматы | Максимальный размер |
|---------------|--------------------|----------------------|
| Текстовые материалы (доклад, бизнес-план, паспорт) | .doc, .docx, .pdf | 5 МБ |
| Презентационные материалы | .ppt, .pptx, .pptm, .pdf | 10 МБ |

ФИО участников указываются в соответствии с паспортными данными. Работа может быть представлена только на одну секцию. Команда — не более трёх человек (лидер и два участника) без учёта руководителя.

## Конвертация Markdown в Word/PDF

Текущие документы в формате Markdown (.md). Для загрузки на сайт конференции их нужно преобразовать в .docx или .pdf:

1. **Pandoc** (командная строка):  
   `pandoc 01-biznes-plan.md -o 01-biznes-plan.docx`  
   Аналогично для паспорта.

2. **Редакторы с экспортом:** VS Code / Cursor с расширениями для Markdown, Typora, Notion и др. — экспорт в Word или PDF.

3. **Онлайн-конвертеры:** вставить содержимое .md в сервис конвертации Markdown → Word/PDF.

После конвертации проверьте оформление (титульная страница, оглавление, таблицы) и при необходимости подправьте в Word перед сохранением в .pdf.
