# Запуск бэкенда на своём компьютере

Чтобы приложение MedGuide обращалось к бэкенду на вашем ПК, а не на удалённом сервере, сделайте два шага: запустите бэкенд локально и укажите приложению его адрес.

---

## 1. Запуск бэкенда на ПК

Бэкенд проекта (Django) обычно лежит в папке `backend` рядом с `react-medguide`.

1. Откройте терминал и перейдите в папку бэкенда:
   ```bash
   cd d:\medguide\backend
   ```
   (или путь, где у вас лежит проект с `manage.py`.)

2. Создайте и активируйте виртуальное окружение (если ещё не сделано):
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. Установите зависимости и выполните миграции:
   ```bash
   pip install -r requirements.txt
   python manage.py migrate
   ```

4. Запустите сервер так, чтобы он был доступен с других устройств в сети (телефон, эмулятор):
   ```bash
   python manage.py runserver 0.0.0.0:8000
   ```
   Сервер будет слушать порт 8000 на всех интерфейсах. В браузере на этом же ПК можно проверить: http://localhost:8000/

---

## 2. Настройка приложения на адрес вашего бэкенда

Приложение берёт адрес API из переменной окружения или из встроенных значений по умолчанию.

### Вариант A: эмулятор или браузер на этом же ПК

Ничего настраивать не нужно, если бэкенд запущен на том же компьютере:

- **Web (браузер):** по умолчанию используется `http://localhost:8000`
- **Android-эмулятор:** по умолчанию используется `http://10.0.2.2:8000` (так эмулятор обращается к localhost ПК)
- **iOS-эмулятор:** по умолчанию используется `http://localhost:8000`

Просто запустите бэкенд командой из пункта 1 и приложение (Expo) на эмуляторе или в браузере.

### Вариант B: телефон или планшет в одной Wi‑Fi сети с ПК

На телефоне «localhost» — это сам телефон, поэтому нужно указать **IP вашего компьютера** в локальной сети.

1. Узнайте IP вашего ПК в Windows:
   ```bash
   ipconfig
   ```
   Найдите «IPv4-адрес» для активного подключения (часто Wi‑Fi), например `192.168.1.100`.

2. В корне проекта `react-medguide` создайте файл `.env` (если его ещё нет) и задайте базовый URL бэкенда **без** суффикса `/api/`:
   ```env
   EXPO_PUBLIC_API_BASE_URL=http://192.168.1.100:8000
   ```
   Подставьте свой IP вместо `192.168.1.100`.

3. Перезапустите Expo (остановите и снова запустите `npx expo start`), чтобы подхватилась новая переменная.

После этого приложение на телефоне будет обращаться к бэкенду на вашем компе по адресу `http://192.168.1.100:8000`.

---

## Краткая сводка

| Где запущено приложение | Где запущен бэкенд | Что указать |
|-------------------------|--------------------|-------------|
| Тот же ПК (Web / эмулятор) | ПК, `runserver 0.0.0.0:8000` | Ничего (по умолчанию localhost / 10.0.2.2) |
| Телефон в Wi‑Fi | ПК в той же сети | В `.env`: `EXPO_PUBLIC_API_BASE_URL=http://IP_ПК:8000` |

Если что-то не открывается, проверьте, что брандмауэр Windows не блокирует входящие подключения на порт 8000.
